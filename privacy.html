Privacy

Your answers to the 40 statements are scored in your browser. They are not sent to Dr Elijah Ting, and they are not stored, unless you later choose to paste them into a message yourself. When a type has been computed, that completed profile is stored at big5.drelijah.org under a result number, with no name and no email. What is stored is the four-letter type and a short note of each letter-pair. The results page shows the result number so you can quote it if you get in touch. Under Malaysia’s Personal Data Protection Act, the stored profile is linked to your name or email only if you send the enquiry form and opt in. If a result number cannot be issued, the type is still shown in this browser and that profile is not stored.

If you have completed the profile in this browser, the enquiry form lets you opt in to share the result with Dr Elijah Ting. The result is sent only if you tick that option and then send the enquiry. If you leave it unticked, or if there is no completed result, the enquiry does not include it. The result number is sent only when you tick that option. If the box is left unticked, the number is not sent. When you opt in, the form sends your four-letter type and a short note of each letter-pair: the score, which side it leaned to, and whether a pair was evenly balanced. If this browser already has a result number for that completion, the form sends that number as well. It does not send your answers to the 40 statements. The type and the note are stored with the enquiry at big5.drelijah.org so he can see them when he replies. Under Malaysia’s Personal Data Protection Act, that is personal data used only to answer your enquiry. You can ask for it to be deleted by emailing elijah@drelijah.org. To delete a stored profile, include its result number.

If you use the enquiry form, your name, email, organisation (if you give one), the topic you choose and your message are sent to the practice’s enquiry system at big5.drelijah.org. They are stored there so that Dr Elijah Ting can reply, and he is alerted to each new enquiry by email and by private message. Those enquiry emails are copied to a second inbox used for practice administration, under Malaysia’s Personal Data Protection Act. They are not used for any other purpose. Completing the profile does not create an enquiry. Someone who only takes the test is not stored under a name or an email address.
